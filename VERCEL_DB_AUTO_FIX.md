## 🚀 Cara Jalankan Script

### Step 1: Clone atau Pull Latest Code

```bash
# Jika belum clone
git clone https://github.com/safir2310/ayamgeprekku.git
cd ayamgeprekku

# Jika sudah clone
git pull origin master
```

### Step 2: Setup Token Vercel

Buat file `.vercel-token.env` di root project:

```env
VERCEL_TOKEN=your_vercel_token_here
```

**Get token dari**: https://vercel.com/account/tokens

### Step 3: Install Dependencies

```bash
bun install
```

### Step 4: Jalankan Script

```bash
# Linux/Mac
bash fix-vercel-db.sh

# Windows (Git Bash)
bash fix-vercel-db.sh

# Windows (PowerShell)
bash fix-vercel-db.sh
```

## 🎯 Langkah Selanjutnya untuk Deployment

### Step 1: Add NEXTAUTH_SECRET ke Vercel

1. Buka Vercel Dashboard: https://vercel.com/dashboard
2. Pilih project
3. Settings → Environment Variables
4. Add new:
   - Name: `NEXTAUTH_SECRET`
   - Value: (akan ditampilkan setelah script berjalan)
   - Environments: Production, Preview, Development
5. Save

### Step 2: Deploy ke Vercel

1. Deployments → Redeploy
2. Tunggu deployment selesai

### Step 3: Update NEXTAUTH_URL

Setelah deployment selesai:

1. Copy production URL
2. Update NEXTAUTH_URL:
   - Production: `https://ayamgeprekku.vercel.app`
3. Redeploy lagi

## 🔍 Troubleshooting

### Error: "Invalid Vercel Token"

**Solution:**
- Cek token di `.vercel-token.env`
- Generate baru di: https://vercel.com/account/tokens
- Update file dan jalankan script lagi

### Error: "Project not found"

**Solution:**
- Import project ke Vercel: https://vercel.com/new
- Pastikan nama project cocok

### Error: "Database already exists"

**Solution:**
- Database sudah dibuat, tidak perlu dibuat lagi
- Script akan melanjutkan dengan database yang ada

### Error: "jq not found"

**Solution:**
```bash
# Ubuntu/Debian
sudo apt-get install jq

# MacOS
brew install jq

# Atau gunakan .env.example untuk manual setup
```

### Error: "Database connection failed"

**Solution:**
- Tunggu beberapa menit setelah database creation
- Vercel butuh waktu untuk setup database baru
- Coba `bun run db:push` lagi setelah script selesai
