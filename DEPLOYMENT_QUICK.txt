┌──────────────────────────────────────────────────────────────────────┐
│ 🔧 TROUBLESHOOTING                                                │
└──────────────────────────────────────────────────────────────────────┘

Problem: Deployment fails
───────────────────────────
Solution:
  • Check build logs in Vercel Dashboard
  • Verify all dependencies are in package.json
  • Ensure prisma generate runs in build (check postinstall script)


Problem: Database connection error
───────────────────────────────────
Solution:
  • Verify all POSTGRES_ variables are correct
  • Check database is active in Prisma Cloud
  • Ensure SSL is enabled (sslmode=require)


Problem: Auth not working
───────────────────────────
Solution:
  • Check NEXTAUTH_SECRET is set
  • Verify NEXTAUTH_URL matches deployment URL
  • Use HTTPS for NEXTAUTH_URL


Problem: Features not working
───────────────────────────────
Solution:
  • Check function logs in Vercel Dashboard
  • Verify database queries are successful
  • Ensure Prisma Client is generated
  • Check for runtime errors

Update Code

  git push origin master

Update Schema
────────────
  # 1. Edit prisma/schema.prisma
  # 2. Create migration
  bun run db:migrate --name your_changes

  # 3. Push to GitHub
  git add prisma/migrations
  git commit -m "db: add migration"
  git push origin master

Update Environment Variables
───────────────────────────
  1. Go to Vercel Dashboard
  2. Settings → Environment Variables
  3. Edit or add variable
  4. Save and Redeploy
